How Lat/Lon Becomes a Screen Position

The Earth is a 3D sphere, while your computer screen is a 2D flat grid of pixels (x, y). Converting latitude and longitude coordinates into pixel coordinates requires a Cartographic Projection.

1. Flat World (Equirectangular Projection)

The simplest method maps the spherical coordinates uniformly onto a rectangle of width W and height H:

x = ((lon + 180) / 360) * width
y = ((90 - lat) / 180) * height

• Longitude spans from -180° to +180° (360° total). Adding 180 normalizes it to [0, 360], and dividing by 360 gives a fraction from 0.0 (left edge) to 1.0 (right edge).
• Latitude spans from +90° (North) to -90° (South). In computer graphics, pixel y = 0 is at the top. Subtracting lat from 90 flips the axis so North is at the top.

2. Web Mercator (Used by Leaflet & OpenStreetMap)

Leaflet uses EPSG:3857 (Web Mercator). Unlike equirectangular projection, Mercator preserves shapes and angles (conformal), which prevents landmasses from looking distorted at local zoom levels, but stretches the poles to infinity:

x = (lon + 180) / 360 * 256 * 2^zoom
y = (1 - ln(tan(lat_rad) + sec(lat_rad)) / π) / 2 * 256 * 2^zoom

Leaflet performs this math under the hood via map.project(latlng, zoom) and positions the DOM marker element using CSS transform: translate3d(x px, y px, 0)!
